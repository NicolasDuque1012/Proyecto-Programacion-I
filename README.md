## Project Description
This project consists of exploring, cleaning and analysing a dataset of the top 100 movies using Python, Pandas, NumPy and Matplotlib.

## Kaggle Dataset
Dataset: Top 100 Movies

CSV file used:https://github.com/SteadyHands01/top100-movies-visualisation/blob/main/top_100_movies_full_best_effort.csv
## Project Files
- `main.py`: Dataset exploration, data cleaning, statistical analysis and visualizations.
- `funciones_proyecto.py`: Custom functions used in the analysis.
- `pruebaKaggle.py`: Interactive movie search program.
